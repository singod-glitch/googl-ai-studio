# Real-Time Stock Trend Dashboard 📈

A quantitative trading dashboard designed to track and visualize macroeconomic indicators and alternative data (search trends) in real-time. 

## 🚀 Project Overview
This project aims to integrate global search interest data with stock price momentum. The architecture is ready to ingest consistently scaled trend data (e.g., Google Trends API) to evaluate market sentiment and identify early trading signals across global supply chains.

## 🛠 Tech Stack
*   **Environment:** [Bun](https://bun.sh/)
*   **Build Tool:** Vite
*   **Language:** TypeScript (`server.ts`, etc.)
*   **Integration:** Designed to be integrated with Google Cloud Platform (GCP) and BigQuery for large-scale data processing.
